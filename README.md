# Щоденник

Мобільний криптожурнал (PWA): спот, ф'ючі, нотатки по монетах і власний план. Дані зберігаються на телефоні (IndexedDB), застосунок працює без інтернету.

## Запуск

```bash
npm install
npm run dev      # розробка
npm test         # тести розрахунків
npm run build    # збірка в dist/
```

## Структура

- `src/core` — чисті функції розрахунків і форматування (без React), з тестами
- `src/data` — IndexedDB (Dexie), зміни даних, ціни, резервна копія
- `src/screens`, `src/sheets`, `src/ui` — екрани, нижні шторки, елементи інтерфейсу
